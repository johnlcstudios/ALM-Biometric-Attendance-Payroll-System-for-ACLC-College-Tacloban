## 2026-06-14 - [Accessible Password Toggles in Legacy Forms]
**Learning:** In legacy PHP/Bootstrap environments lacking native component abstractions, password visibility toggles must be manually augmented with `role="button"`, `tabindex="0"`, and dual event listeners (click + keydown) to ensure keyboard parity with mouse users. Additionally, centralizing password field styling (75px right padding for inputs, 45px right positioning for icons) ensures layout stability and prevents text overlap when visibility is toggled.
**Action:** Always include `tabindex="0"` and a keydown listener (Enter/Space) when transforming non-interactive elements (like `<i>` icons) into functional UI controls. Use the centralized `.password-field` and `.toggle-password` classes in `css/style.css` to maintain visual consistency.
